Liability Reduction Options (LRO) are damage-liability tiers offered to customers during booking. Each tier defines a daily rate, excess fee, and coverage benefits. Customers select the tier that suits their risk preference, and the selected option is applied to the booking cost.

## Viewing Liability Options

Click Liability Options in the sidebar to see all configured tiers. Use the All Options tab and Search box, or Reset to clear filters.

## Adding a New Liability Option

**URL:** https://app.fleetros.com/liability-options/new

1. Click the + Add Option button.
2. Under Basic Information, enter the Option Name and Code (both required, the Code is a unique identifier in uppercase with underscores). Add an optional Description and set the Tier Order (0 is the lowest coverage tier). Toggle Active to enable the option.
3. Under Pricing, enter the Daily Rate and Excess Fee (in your configured currency).
4. Click Save to create the option, or Cancel to discard.

> **Tip:** Tier Order determines the display sequence when customers choose their coverage level. Use 0 for the most basic tier and increment for higher coverage levels.
